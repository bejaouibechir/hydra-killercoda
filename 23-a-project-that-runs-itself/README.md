# 23. A project that runs itself

Killercoda lab for `[LAB lab-03-06]` in `DSL-whitebook/03-workflows.md`.

The lesson uses only its two projects and a localhost Hydra API. `hdrctl watch` handles cron, file and after_project; `hdrctl serve` handles HTTP webhook. No Docker, security scans or external network requests during the lesson. Generated locally for review; do not push before review.
