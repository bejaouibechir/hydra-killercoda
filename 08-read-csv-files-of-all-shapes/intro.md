# Read CSV files of all shapes

The same rows can be stored with different separators and encodings. In this lab you will read three versions of one dataset:

1. A comma-separated UTF-8 file.
2. A semicolon-separated UTF-8 file.
3. A semicolon-separated Latin-1 file.

You will observe two deliberate mistakes, fix the source settings, and compare the results.

**Time:** about 15 minutes. **Prerequisite:** basic YAML indentation.

Hydra ETL 0.16.0 installs in the background. The jobs are in `/root/lab/csv-shapes/jobs/`. No database, credentials or external data service is needed.
