# Draw the graph

Edit `graph.md` as a Mermaid `flowchart LR`. Add one `A --> B` line for each direct dependency in `workflow.yaml`. Draw all five named steps and five arrows. The starter file has a comment but no arrows.

```bash
cd /root/lab/draw-workflow
cat graph.md
```

Use the editor to add your arrows, save the file, and press **Check**. The checker compares your graph with the YAML and the measured run order.
