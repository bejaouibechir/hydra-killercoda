# Meet hdrctl

Hydra ETL's CLI is `hdrctl`. Before writing a single pipeline, it's worth knowing what it can already tell you.

In this lab you will:

1. discover `hdrctl`'s own commands and options;
2. scaffold a project with `hdrctl init` — one job, and the workflow that runs it;
3. validate and run that workflow;
4. let `hdrctl list` check what you read.

No data to prepare, no service to start. `hdrctl` is installing while you read.
